# Specs

All planning documents for this project.

## Directory Structure

- `product/` - Product vision, scope, glossary
- `tech-architecture/` - Technology stack, test plan, security plan, design plan
- `epics/` - Epic capsules with stories and tasks
- `bugs/` - Bug investigations and registry
- `adr/` - Architecture Decision Records
- `verifications/` - Verification plans and results

## Key Files

- `state.yaml` - Session state and workflow tracking
- `release-plan.yaml` - Release index and epic list
- `execution-status.yaml` - Story/epic execution status
- `planning-status.yaml` - Discover-phase checklist
