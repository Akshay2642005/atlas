# BUG-001: request_id_middleware is not async — 500 on every request

**Severity:** Critical (all requests return 500)
**Status:** Fixed
**Scope:** `atlas_api.middlewares.request_id_middleware`

## Summary

`request_id_middleware` is defined as a plain `def` function, but `call_next` is
an async callable that must be awaited. Without `await`, the result of
`call_next(request)` is a raw coroutine object, not a `Response`. Accessing
`.headers` on it raises:

```
AttributeError: 'coroutine' object has no attribute 'headers'
```

This crashes **every** incoming request with HTTP 500, making the server completely
non-functional.

## Root Cause

```python
# BEFORE (broken)
def request_id_middleware(request: Request, call_next):
    rid = request.headers.get("X-Request-ID") or str(uuid.uuid4())
    structlog.contextvars.bind_contextvars(request_id=rid)
    try:
        response = call_next(request)          # ← coroutine, not awaited
        response.headers["X-Request-ID"] = rid # ← AttributeError here
        return response
    finally:
        structlog.contextvars.unbind_contextvars()
```

## Fix

Add `async` / `await` to make the middleware a proper async function:

```python
# AFTER (fixed)
async def request_id_middleware(request: Request, call_next):
    rid = request.headers.get("X-Request-ID") or str(uuid.uuid4())
    structlog.contextvars.bind_contextvars(request_id=rid)
    try:
        response = await call_next(request)
        response.headers["X-Request-ID"] = rid
        return response
    finally:
        structlog.contextvars.unbind_contextvars()
```
